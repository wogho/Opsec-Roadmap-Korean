# 모바일과 물리보안

모바일 단말은 인증 수단, 복구 채널, 위치 센서, 연락처와 대화를 한곳에 모은다. 분실 한 번이 여러 신뢰 경계의 동시 실패가 되지 않도록 설계한다.

## 기준선

긴 PIN 또는 강한 암호, 짧고 현실적인 자동 잠금, 저장 암호화, 최신 보안 업데이트, 잠금 화면 알림 최소화를 사용한다. 생체인증은 편의성과 주변 관찰 위험, 법적 환경을 함께 고려한다. SIM 계정 PIN·통신사 계정 보호와 번호 이전 방지 옵션을 확인한다.

앱 권한은 기능에 필요한 동안만 허용하고, 연락처·정확한 위치·마이크·사진 전체 접근을 정기 검토한다. Android와 Apple의 사설 Wi-Fi 주소는 로컬 식별자 하나를 줄이지만 계정 로그인, IP, 위치, 다른 무선 신호까지 익명화하지 않는다.

## 물리 접근

단말을 맡겨야 하는 수리·검색·여행 상황은 별도 시나리오로 모델링한다. 필요한 데이터만 가져가고, 검증된 백업을 만든 뒤, 반환 후 부팅·계정·관리 프로필·등록된 인증 수단을 확인한다. 변조 방지 봉인은 탐지를 보조할 뿐 정교한 변조를 배제하지 않는다.

## 분실 대응

연락 담당자, 원격 잠금의 선행 조건, 세션 폐기 순서, SIM·결제 정지, 백업 복원 절차를 미리 정한다. 원격 삭제 성공 여부를 보장하지 말고, 저장 암호화와 최소 데이터 보관을 1차 방어로 둔다.
