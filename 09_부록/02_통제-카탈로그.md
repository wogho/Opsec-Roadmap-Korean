# 통제 카탈로그

통제 ID는 추적을 위한 식별자이며 인증이나 적합성 표시가 아니다. 실제 적용은 [위협 모델](03_위협-모델-워크시트.md)과 [위험 평가](../01_OPSEC-기초/03_위험평가와-통제선정.md)를 거친다.

| ID | 통제 | 유형 | 대표 위협 | 검증 증거 |
|---|---|---|---|---|
| IAM-01 | 서비스별 고유 비밀번호와 관리자 | 예방 | 자격 증명 대입 | 중복 감사, 금고 복구 시험 |
| IAM-02 | 패스키·FIDO2 보안 키 | 예방 | 실시간 피싱 | 등록 수단·대체키·로그인 시험 |
| IAM-03 | 세션·연동 앱 검토 | 탐지/대응 | 세션 탈취 | 활성 세션 대조, 폐기 기록 |
| DEV-01 | 지원 버전과 자동 패치 | 예방 | 공개 취약점 | 버전·패치 지연 보고서 |
| DEV-02 | 저장 암호화와 복구키 분리 | 예방/복구 | 물리 탈취 | 잠금 상태·복구 시험 |
| DEV-03 | 목적에 비례한 격리 | 예방 | 단말 내 횡적 확장 | 공유 경계·우회 경로 시험 |
| NET-01 | 관찰자별 데이터 흐름도 | 관리 | 메타데이터 결합 | 최신 흐름도·가정 목록 |
| NET-02 | 관리된 VPN 또는 Tor Browser | 예방 | 경로 관찰 | 경로·DNS·장애 동작 시험 |
| DAT-01 | 수집·보존 최소화 | 예방 | 불필요한 노출 | 표본 수명주기 추적 |
| DAT-02 | 독립·불변/오프라인 백업 | 복구 | 랜섬웨어·잠금 | 격리 복원 기록 |
| COM-01 | 중요 요청의 별도 채널 확인 | 예방 | 사칭·업무 이메일 침해 | 훈련·확인 기록 |
| OPS-01 | 행동 가능한 보안 경보 | 탐지 | 계정·설정 변경 | 경보 수신·처리 시간 |
| OPS-02 | 연습된 사고 대응·대체 연락 | 대응 | 서비스·계정 중단 | 모의훈련 결과 |

통제마다 책임자, 적용 범위, 예외, 실패 영향, 잔여 위험, 다음 시험일을 [결정 기록](../templates/통제-결정-기록.md)에 남긴다.
