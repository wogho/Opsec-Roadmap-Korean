# OPSEC 점검표

체크 표시는 증거 링크가 있을 때만 완료로 본다.

## 설계

- [ ] 시나리오별 자산·행위자·신뢰 경계·비목표가 문서화됨
- [ ] 생명·신체·법적 영향과 가용성이 평가됨
- [ ] 통제별 보호 범위, 우회 경로, 잔여 위험이 기록됨
- [ ] 복잡성이 운영 역량과 위험에 비례함

## 신원·단말

- [ ] 중요 계정에 고유 비밀번호와 피싱 저항 인증 적용
- [ ] 복구 수단이 독립 보관되고 실제 시험됨
- [ ] 활성 세션·연동 앱·관리 계정이 검토됨
- [ ] 지원되는 단말, 자동 패치, 저장 암호화가 확인됨
- [ ] 브라우저 확장·앱 권한·자동 실행이 최소화됨

## 데이터·통신

- [ ] 고위험 데이터의 생성부터 삭제까지 추적됨
- [ ] 백업이 운영 계정과 독립되고 복원 시험됨
- [ ] 공개 분석 서비스에 민감 파일을 올리지 않음
- [ ] 수신자·백업·알림·메타데이터 위험이 평가됨
- [ ] 공개 게시물의 위치·시간·관계·문체 신호를 검토함

## 운영·대응

- [ ] 중요한 변경과 예외에 책임자·만료일·되돌리기 절차가 있음
- [ ] 경보가 행동 가능하며 과도한 수집·보존을 하지 않음
- [ ] 대체 연락과 사고 대응이 연습됨
- [ ] 최신 시험 결과와 실패 개선 조치가 연결됨
