# 용어집

| 용어 | 뜻 |
|---|---|
| 자산 | 보호 가치가 있는 정보, 기능, 신원, 관계, 평판, 신체 안전 또는 복구 능력 |
| 위협 행위자 | 자산에 해를 줄 의도 또는 능력을 가진 개인·집단·서비스·사건 |
| 취약성 | 위협이 악용할 수 있는 설계·구현·운영상의 약점 |
| 공격 경로 | 공격자가 초기 조건에서 피해까지 도달하는 단계와 의존성 |
| 신뢰 경계 | 데이터나 권한이 다른 통제·책임 영역으로 넘어가는 지점 |
| 고유 위험 | 통제를 고려하기 전의 위험 |
| 잔여 위험 | 통제 적용 후에도 남는 위험 |
| 메타데이터 | 내용의 생성·전송·관계·시간·위치·크기 등을 설명하는 데이터 |
| 구획화 | 한 영역의 침해·오류가 다른 영역으로 확장되는 범위를 줄이는 분리 |
| 피싱 저항성 | 가짜 검증자에게 인증 비밀을 제공해도 정상 서비스 로그인으로 재사용하기 어려운 성질 |
| 종단간 암호화 | 통신 종단이 가진 키로 내용을 보호해 중간 서비스가 평문을 읽지 못하게 하는 설계 |
| RPO | 사고 시 허용 가능한 데이터 손실 시점 범위 |
| RTO | 업무 기능을 복구해야 하는 목표 시간 |

용어는 [[00_백서-안내/03_기준-위협-모델|기준 위협 모델]]과 [[02_통제-카탈로그|통제 카탈로그]]에서 같은 의미로 사용한다.
