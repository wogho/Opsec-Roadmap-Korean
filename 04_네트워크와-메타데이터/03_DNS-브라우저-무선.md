# DNS, 브라우저, 무선

## DNS

암호화 DNS는 단말과 선택한 재귀 확인자 사이의 질의 내용을 보호할 수 있지만 확인자는 질의를 보며, IP·시간·트래픽 분석 가능성은 남는다. 운영체제, 브라우저, VPN이 서로 다른 확인자를 쓰는지 확인하고, 공급자의 보존·관할·장애 처리 정책을 평가한다.

## 브라우저

브라우저를 최신 상태로 유지하고 확장 수를 줄인다. 사이트별 권한, 저장된 세션, 다운로드 자동 열기, 동기화 범위를 검토한다. 일반 활동은 목적별 프로필로 분리할 수 있지만, 높은 익명성 목표에서는 독특한 사용자 에이전트·확장·화면 크기 조정이 오히려 식별 신호가 될 수 있다.

## Wi-Fi와 Bluetooth

자동 연결과 불필요한 검색을 끄고, 공유기 관리자 암호·펌웨어·현대적 무선 암호화를 관리한다. 사설 MAC 주소는 추적 신호 하나를 줄이지만 네트워크 로그인, DHCP 정보, 무선 특성, 위치 서비스와 앱 SDK가 다른 연결점을 남길 수 있다. Bluetooth는 사용하지 않을 때 검색 가능 상태와 권한을 제한한다.

공용 Wi-Fi는 “사용했다”는 이유만으로 모든 암호화 통신이 즉시 노출되는 것은 아니지만, 악성 포털·잘못된 인증서 경고·근거리 관찰 위험이 커진다. 중요한 관리 작업은 신뢰 가능한 단말과 검증된 암호화 연결에서 수행한다.
