# VPN, Tor, 프록시

## VPN

VPN은 단말과 VPN 게이트웨이 사이의 경로를 보호하고 로컬 네트워크·ISP가 목적지 일부를 직접 보는 것을 줄일 수 있다. 그러나 VPN 이후의 트래픽, 목적지 계정, 단말 쿠키를 없애지 않으며 관찰 지점을 VPN 사업자에게 일부 이동한다. 관할, 소유 구조, 인증 방식, 업데이트, 로그 정책과 독립 검증의 범위를 평가한다.

## Tor Browser

Tor Browser는 다중 중계와 공통 브라우저 설정으로 출발지 연결과 브라우저 지문 위험을 줄이도록 설계되었다. 추가 확장 설치, 창·설정의 독특한 변경, 외부 앱으로 파일 열기, 실명 계정 로그인은 보호 목표를 약화할 수 있다. Tor는 손상된 단말, 사용자가 직접 밝힌 정보, 종단의 악성 콘텐츠, 강한 전역 상관분석을 해결한다고 가정하지 않는다.

## 조합 판단

VPN과 Tor를 겹친다고 이점이 자동으로 합산되지 않는다. 누가 어느 경로를 보는지, 장애 시 트래픽이 어떻게 흐르는지, 계정 연결이 남는지를 데이터 흐름도로 검토한다. 복잡한 체인은 고유 지문, 속도 저하, DNS 누출, 잘못된 장애 전환을 만들 수 있다.

## 검증

기대하는 출구 IP·DNS 경로, IPv6, 브라우저 외 앱, 재부팅과 네트워크 변경 후 동작을 시험한다. 누출 시험 사이트의 단일 결과를 익명성 증명으로 사용하지 않는다. 공식 Tor Browser 업데이트를 유지하고 [[03_기기와-플랫폼/01_플랫폼-선정과-격리|단말 신뢰]]를 별도로 관리한다.
