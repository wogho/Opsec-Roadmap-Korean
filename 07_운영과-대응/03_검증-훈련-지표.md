# 검증, 훈련, 지표

## 검증 계층

설정 확인은 가장 낮은 단계다. 다음으로 기능 시험, 실패 주입, 복구 연습, 독립 검토를 수행한다. 예를 들어 “백업 켜짐”은 설정 확인이고, 빈 환경에 필요한 시간 안에 복원해 해시와 애플리케이션을 확인해야 효과 증거가 된다.

## 핵심 시험

- 보안 키 분실·휴대전화 교체 후 계정 복구
- 악성 로그인 경보 수신부터 세션 폐기까지
- 패치 실패와 미지원 소프트웨어 탐지
- 단말 분실 시 연락·잠금·복구
- 오프라인 또는 불변 백업에서 복원
- 담당자 부재 중 사고 연락망과 권한 위임

## 지표

통제 설치 수보다 패치 지연, 고위험 계정의 피싱 저항 인증 비율, 복원 성공률, 중대 경보 확인 시간, 만료되지 않은 예외, 반복되는 절차 우회와 같은 결과 지표를 쓴다. 평균만으로 심각한 꼬리 위험을 숨기지 않고 실패 사례를 별도 검토한다.

## 훈련 원칙

훈련은 사람을 함정에 빠뜨려 점수를 매기는 행사가 아니다. 역할과 중단 기준을 알리고, 실제 도구와 연락 경로를 사용하며, 안전·업무 영향이 커지면 즉시 중단한다. 결과는 개인 비난이 아니라 설계와 절차 개선으로 연결한다.
