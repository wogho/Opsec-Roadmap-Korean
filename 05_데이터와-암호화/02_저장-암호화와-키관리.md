# 저장 암호화와 키관리

## 보호 범위

전체 디스크 암호화는 꺼져 있거나 잠긴 기기의 분실·탈취 위험을 줄인다. 파일·컨테이너 암호화는 공유와 별도 보관 경계를 만들 수 있다. 둘 다 잠금 해제된 단말의 악성코드, 화면 캡처, 수신자 공개를 막지 못한다.

검증된 표준 알고리즘과 유지되는 구현을 사용한다. 독자 암호 설계, 출처 불명 앱, “군사용” 같은 마케팅 문구를 근거로 선택하지 않는다. VeraCrypt 같은 컨테이너 도구도 운영체제·암호·키 보관·마운트 상태에 의존하며, 그럴듯한 부인 가능성을 보장한다고 표현하지 않는다.

## 키 수명주기

키 생성, 접근, 백업, 교체, 폐기와 복구 책임자를 정한다. 데이터와 키를 같은 계정·단말·장소에만 보관하지 않는다. 하드웨어 보안 모듈·보안 키는 추출 저항성을 높일 수 있지만 분실·호환성·복구 위험을 추가한다.

복구키는 접근 통제를 갖춘 별도 위치에 두고, 존재와 가독성을 정기 확인한다. 키 교체는 새 데이터뿐 아니라 기존 암호문·백업·수신자 사본의 처리 범위를 명확히 해야 한다.

## 검증

전원이 꺼진 상태와 잠금 상태에서 보호가 적용되는지, 부팅·복구 경로가 우회하지 않는지, 복구키로 실제 복원이 가능한지 시험한다. 로그에 키나 평문이 남지 않는지도 확인한다.
