# 문서 규범과 근거 등급

## 규범어

- **MUST(필수)**: 위협 모델의 보호 목표를 달성하려면 반드시 지켜야 한다. 예외는 책임자·기간·보완 통제와 함께 기록한다.
- **SHOULD(권고)**: 일반적으로 이익이 크지만, 비용·접근성·위험 차이로 다른 선택이 가능하다. 생략 이유를 남긴다.
- **MAY(선택)**: 특정 환경에서 유용한 선택지다. 채택하지 않아도 비준수로 보지 않는다.

규범어가 없는 설명은 정보 제공이다. “안전하다”, “익명이다” 같은 절대 표현은 공격자 능력과 조건이 명시되지 않으면 사용하지 않는다.

## 근거 등급

| 등급 | 근거 | 사용 원칙 |
|---|---|---|
| A | 표준·정부 지침·검증된 설계 문서 | 기준 통제의 우선 근거 |
| B | 공급자의 공식 보안·운영 문서 | 제품 기능과 제한 확인 |
| C | 재현 가능한 독립 연구·시험 | 구현 위험과 비교 보완 |
| D | 전문가 경험·사례·합리적 추론 | 가설로 표시하고 검증 계획 첨부 |

오래된 근거나 특정 제품 버전에 기대는 근거에는 검토일과 적용 버전을 붙인다. 출처가 많다는 사실만으로 주장이 강해지지는 않는다. 해당 주장을 직접 뒷받침하는지, 지금도 유효한지, 이해충돌은 없는지를 살핀다.
