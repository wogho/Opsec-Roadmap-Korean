# 메시징, 이메일, 회의

## 채널 선택

메시지 내용의 종단간 암호화, 메타데이터 보유, 연락처 발견 방식, 기기 연결, 백업, 계정 복구, 관리자 권한, 삭제 의미를 비교한다. Signal과 같은 종단간 암호화 메신저도 잠금 해제된 단말, 악성 알림 미리보기, 수신자의 전달·촬영, 관계와 접속 시간의 모든 노출을 없애지는 않는다.

이메일은 서버 간·서버 내 저장과 전달 경로가 다양하다. 전송 암호화만으로 종단간 기밀성을 가정하지 않고, 민감 첨부는 [별도 파일 공유 통제](../05_데이터와-암호화/04_파일-수신-검증-공유.md)를 적용한다. 발신자 표시 이름과 회신 주소만 믿지 말고 중요한 요청은 알려진 별도 채널로 확인한다.

## 회의

참가자 인증, 대기실, 녹화 권한, 자막·전사 서비스, 화면 공유 범위, 배경과 알림 노출을 관리한다. 회의 링크를 공개 게시하지 않고, 녹화가 필요하면 목적·접근자·보존 기간과 동의를 정한다.

## 검증

새 기기 연결 알림, 안전 번호 또는 상대 확인 기능, 백업 설정, 잠금 화면 노출을 정기 점검한다. 사고 대응 연락망은 주 통신 서비스가 중단되거나 계정이 잠겨도 사용할 수 있는 대체 채널을 갖는다.
